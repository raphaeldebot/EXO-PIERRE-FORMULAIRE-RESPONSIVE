# Exercice : Formulaire responsive
## Créer un formulaire responsive avec les champs suivants :

1) un fieldset "Votre identité" reprenant nom et prénom

2) un fieldset "Vos coordonnées reprenant rue, numéro, code postal, ville

3) un fieldset "Vos préférences" reprenant :

- la langue utilisée (boutons radio : Français, Néerlandais, Allemand, Anglais)

- les activités (cases à cocher : Cinéma, Sport, Lecture, Jeux Vidéo)

4) une zone de texte "Votre message"

5) une checkbox de consentement "Acceptez-vous que vos données soient stockées ?"

6) un bouton d'envoi
 
## Pour l'affichage des écrans de largeur < 600px

- Les labels dans "Votre identité", "Vos coordonnées", "Votre message" sont au-dessus des champs associés

- les autres labels (boutons radio et cases à cocher) sont à côté

- les fieldsets sont les uns au-dessus des autres

- Nom et Prénom sont l'un au-dessus de l'autre

- Rue, Numéro, Code postal, Ville sont les uns au-dessus des autres

- les choix pour la Langue et les Activités sont placés verticalement

- Le Message, le consentement et le bouton d'envoi sont placés verticalement
 
## Pour l'affichage des écrans de largeur entre 600px et 1000px, même chose sauf ce qui suit :

- tous les labels sont à côté des champs associés

- les choix pour la Langue et les Activités sont placés horizontalement
 
## Pour l'affichage des écrans de largeur > 1000px, même chose sauf ce qui suit :

- les fieldsets "Votre identité", "Vos coordonnées", "Vos préférences" sont dans la moitié à gauche

- le reste dans la moitié à droite
